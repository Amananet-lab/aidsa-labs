# AIDSA labs

The workspace for the AI and Data Science for Analysts course labs.

1. Open the link your instructor gave you (the first opening can take a few minutes).
2. In the file list on the left, open **Notebooks**, then the folder for today's lab, then its notebook.
3. Run the first two cells, then work through the notebook from the top.
4. The workspace keeps nothing when it closes: before you leave, choose **File**, then **Download**, to keep your notebook.

`Notebooks/Environment_Check.ipynb` tests that the workspace is ready: run all its cells; every line should read PASS.
`data` and `checkpoints` hold the files the labs read. `requirements.txt` and `runtime.txt` set the Python version and libraries.
Each day's labs are added the evening before.
